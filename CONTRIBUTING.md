# Contributing

Small, focused PRs are welcome — this repo is a hackathon submission first, a
utility second.

## How to contribute

1. Fork the repo and create a branch from `main`.
2. Keep changes scoped: one tool, one fix, or one doc improvement per PR.
3. Add a note to `FRICTION-LOG.md` if you hit a real integration quirk.
4. Open the PR with a clear description + a quick verification log
   (`curl` output, screenshot, or test run).

## Ground rules

- No credentials, tokens, or personal data in code or issues.
- Keep the MCP tools stateless and dependency-light.
- The simulated Alexa+ layer must stay clearly labeled as a simulation.
